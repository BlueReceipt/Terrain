# fixtures/private

Your own campaign files go here, for local checks: the KMZ exported from My Maps, the client's Excel file.

Everything in this folder except this README is ignored by git, so real names, phones and addresses never enter the repository.

When exporting from My Maps, **untick "Keep data up to date with network link KML"**. With it ticked, the file holds only a link to Google's servers and no pins.
